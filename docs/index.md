# France-IOI Knowledge Base

This website is a **documentation hub** for all projects in the France-IOI sphere. It is written for both humans and AI agents to learn about the different projects and how they articulate.

## What belongs here vs elsewhere

### In this knowledge base

- **Presentation** (possibly detailed) of apps, services, libraries, and tools.
- **Governed business rules** and domain behavior.
- **Cross-boundary behavior** (for example how frontend, backend, and operations interact at the edges, and how services interact with each other).
- **Operations essentials** — orientation for deploying, running, and supporting systems across the France-IOI sphere.
- **Working documents** that capture rationale for decisions, so the reasoning can be recovered later.

### What belongs elsewhere

- **Per-application architecture** (folder layouts, implementation detail): use the **application repositories**.
- **Project APIs:** when an API belongs to a project, keep it **autogenerated** in that project’s docs and **link** to it from this knowledge base—do not hand-maintain a full API reference here.

Historical and deliberative material under **`docs/archive/`** is **opt-in** and is **not** default-path truth — see **[Archive (opt-in history)](./archive/README.md)**.
