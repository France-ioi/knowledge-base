# Archive

History and context that should **not** drive day-to-day answers.

- **Discussions** and long threads worth keeping as Markdown
- **Deliberation** — options considered, rejected approaches, meeting summaries, and the “why” behind past choices
- **Abandoned projects** — relevant information after a project or initiative is no longer active
